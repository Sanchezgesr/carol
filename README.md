# Carol 21.09 — Producción Vercel

Esta carpeta está lista para desplegar como sitio estático en Vercel.

Archivos:
- `index.html` — página principal.
- `musica.mp4` — audio integrado en la página.
- `vercel.json` — configuración de Vercel.

Despliegue:
1. Sube esta carpeta a un repositorio de GitHub.
2. En Vercel, crea un nuevo proyecto e importa el repositorio.
3. Framework Preset: Other.
4. Build Command: dejar vacío.
5. Output Directory: `.`
6. Deploy.

Después podrás compartir solamente el enlace público de Vercel.
